# jlib compatibility provenance

This directory preserves the `jlib` compatibility package from
`github.com/blues/jsonata-go` v1.5.4.

The Go sources and upstream tests were copied from the module cache and retain
their original copyright headers. Imports point to this module's compatible
`jtypes` and `jlib/jxpath` packages. Behavior remains upstream-compatible;
changes are limited to import paths and removal of placeholder comments.
